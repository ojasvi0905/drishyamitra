# Drishyamitra

Drishyamitra is a full-stack project that includes a frontend, backend, and WhatsApp service integration.
The project is structured to handle user interaction, server-side processing, and messaging service support.

## 📁 Project Structure

```
drishyamitra-main/
│
├── frontend/          # React frontend application
├── backend/           # Backend server (API / logic)
├── whatsapp-service/  # WhatsApp integration service
├── README.md
├── HOW_TO_RUN.md
```

## 🚀 Features

* Full stack application
* Frontend UI
* Backend API support
* WhatsApp service integration
* Modular project structure

## 🛠️ Technologies Used

* JavaScript / Node.js
* React
* Python (for service scripts)
* Tailwind CSS
* Express (backend)
* Git & GitHub

## ▶️ How to Run the Project

### 1. Clone the repository

```
git clone https://github.com/ojasvi0905/drishyamitra.git
```

### 2. Go to project folder

```
cd drishyamitra-main
```

### 3. Run frontend

```
cd frontend
npm install
npm start
```

### 4. Run backend

```
cd backend
npm install
npm start
```

### 5. Run WhatsApp service

```
cd whatsapp-service
npm install
node index.js
```

## 📌 Notes

* Make sure Node.js is installed
* Install dependencies before running
* Use separate terminals for frontend and backend
